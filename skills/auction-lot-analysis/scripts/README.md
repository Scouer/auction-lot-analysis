# Скрипты навыка

Инструменты для правил «сначала код, потом модель» и «сырьё не проходит через контекст»
(SKILL.md → «Экономика прогона»). Всё детерминируемое делает скрипт; модель включается там,
где нужна интерпретация. Требуется Python 3 и Pillow (`pip3 install pillow`).

| Скрипт | Зачем | Когда |
|---|---|---|
| `fetch_originals.py` | скачать все изображения листинга по манифесту, оригиналы или превью | после инвентаризации, правило v2.0.1 |
| `contact_sheet.py` | собрать все кадры лота в один лист с индексами | найти кадр с нужной зоной за один взгляд |
| `crop.py` | вырезать из оригинала кроп нативного разрешения | **то, что подаётся в зрение** — не оригинал и не превью |
| `run_role.py` + `providers/` | исполнить роль на внешней модели (Perplexity-сбор → GLM/DeepSeek/Gemini) | Историк-ревью, Коллекционер, читатели надписей, переводы — таблица маршрутизации в SKILL.md |

## Порядок

```bash
# 1. превью всех лотов партии — дёшево, для триажа
python3 fetch_originals.py manifest.json ~/work/img/preview --preview \
  --base 'https://image.invaluable.com/housePhotos/EdenFineAntiques/87/816487/H18937-L{}.jpg'

# 2. контакт-лист лота — найти нужный кадр
python3 contact_sheet.py ~/work/img/preview/35

# 3. оригинал нужного кадра + читаемый кроп
python3 fetch_originals.py manifest.json ~/work/img/original \
  --base 'https://image.invaluable.com/housePhotos/EdenFineAntiques/87/816487/H18937-L{}.jpg'
python3 crop.py ~/work/img/original/35/tKHCcNwOHKUUy.jpg 0,3
python3 crop.py ~/work/img/original/35/tKHCcNwOHKUUy.jpg box 0.05 0.28 0.42 0.72
```

Читается результат шага 3. Кроп ≤1600 px по длинной стороне — чтобы его не даунскейлили повторно.

## Где что лежит

Изображения, кропы и контакт-листы — **в vault**: `Projects/antique/lots/<id>/work/` (канон владельца §1:
всё, что не код, — в vault на Drive; `~/Downloads` рабочим каталогом не является, исключение только
`~/Downloads/AI` для библиотеки сканов zisha). Кропы всех проходов — в `crops/` досье, в одном экземпляре (агенты пишут туда напрямую); доказательные =
процитированные в отчёте. Слепой набор — `blind/` досье. В конце прогона удалить `*_up*` и оригиналы чужих
лотов после сборки контакт-листов (`references/archive.md`).

Манифест галерей снимается со страниц лотов и выносится на диск браузерной загрузкой —
`references/platforms.md`, раздел «Вынос данных из браузера на диск».
