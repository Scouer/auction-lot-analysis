# Рынок: источники, ключи компаратов, протокол малых выборок

Роль: Рыночный аналитик. Вход — фактическая ступень атрибуции + физические параметры (категория, размер, материал, состояние из кондишен-строки). Визуальные выводы Рыночному не передаются. Выход — таблица компаратов + вилка «цены объектов с такой атрибуцией» + прогноз молотка.

## Лестница источников

Идти сверху вниз; ступень фиксируется в отчёте (`рынок: ступень N`) и в хвосте. Смешивать ступени можно, помечая каждый компарат.

| Ступень | Источник | Штраф/пометка |
|---|---|---|
| 0 | **Архив Invaluable по всем домам без логина** — `POST /catResults`, индекс `archive_lotNumber_asc_prod`, фильтр `banned:false` (без `houseRef`), `query` — тип предмета + «style / in the style of / Republic / 20th century» для нижнего сценария, без них — для «если by». Брать только `priceResult > 0` с датой; ссылка на лот — `https://www.invaluable.com/auction-lot/_<lotRef>` (`platforms.md`) | первый шаг рынка всегда; молоток или итог в `priceResult` — проверять по странице лота |
| 1 | Архивы проданного под логином (Invaluable, LiveAuctioneers, Artnet, Artprice) — режим M | эталон; молоток и итог раздельно |
| 2 | Бесплатные архивы результатов: Ergebnislisten немецких/австрийских домов, опубликованные price lists, saleroom-результаты, lot-tissimo, аукционные пресс-релизы | хорошо; проверять, молоток или итог |
| 3 | Музейные и справочные базы без цен (V&A, Met, Gotheborg, RKD) | эталон атрибуции, не цены; вилка от сегмента |
| 4 | Дилерские аски | дисконт 40–60% к аску, пометка «аск» |
| 5 | Пресса о рекордах, обзоры | только границы диапазона, не компараты |

## Внешние базы для тестов провенанса (не для цен)

Отдельная задача от компаратов: проверить, **существует ли заявленное свойство за пределами
консигнации** (`consignment.md`, тест 3). Ищется не цена, а факт наличия записей.

| База | Покрытие | Чем полезна |
|---|---|---|
| **雅昌艺搜 (Artron)**, `artso.artron.net` | крупнейшая китайская: Sotheby's, Christie's, 中国嘉德, 北京保利, 西泠, Bonhams | запросы вида `<имя> 上款`, `<имя> 旧藏`, `<художник> <имя>` |
| **帝圖 Artemperor**, `auctions.artemperor.tw` | Тайвань, китайская живопись | независимое подтверждение по тайваньскому обороту |
| artnet / Artprice (под логином) | западный оборот | провенансные строки в описаниях |
| Музейные API (Met, Cleveland, Harvard) | музейные собрания | имя в провенансе или credit line |
| Архивные агрегаторы (SNAC, OAC, finding aids) | личные фонды | есть ли у заявленного собирателя личный архив вообще |

**Обязательное правило контрольного запроса.** Отрицательный результат («ноль записей») не
принимается без запроса, доказывающего, что база ищет и покрывает сегмент. Эталон: `道明先生` → 0
при `齐白石` → 1871 страница и `于右任 上款` → 28 лотов. Без контроля «ноль» — это метка **E-tool**,
а не результат.

Проверять также: что под именем в базе **есть на самом деле** (фотографии и бумаги вместо картин —
сильный сигнал); **омонимов** (совпадение имени ≠ отождествление лица); **однофамильцев в архивах**.

## Правила компаратной таблицы

| Дата | Дом (эшелон) | Лот | Молоток | С премией | Состояние | Отличия от нашего |
|---|---|---|---|---|---|---|

- Только **проданные**, 5–10 за 2–3 года; для узких сегментов окно шире — с пометкой.
- Молоток и итог с премией — раздельно, их путают постоянно.
- Непроданные отдельно: bought-in дважды — вещь «сгорела»; частое всплытие одного предмета — тревожный признак.
- Поправки: состояние, размер, редкость, провенанс, эшелон площадки (региональный ≠ топ).
- Минимум один компарат из дома с реальными каталожными стандартами; нет — строка о неустранимой неопределённости.
- **Результаты самого дома лота — не компарат цены, пока не проверены** (v2.4.7, лот [[2026-10-25-HOTSPOT-455]]). У Hotspot лот 664
  «продан» 06.09.2026 за $1 000 и через 7 недель выставлен снова с тем же главным фото (md5). Перед тем как опереть потолок
  на прошлые продажи дома: (1) по каждой — поиск того же заголовка в более поздних сейлах дома и сверка главного фото;
  вернулась → результат не продажа, исключить; (2) `priceResult` 0 = итог не опубликован, не «не продан»; (3) нижний сценарий
  («копия», «in the style of») — компаратами с **других** площадок (минимум 2, с датой). Канал дома — справочная строка, не база потолка.

## Ключ компаратов по ступени атрибуции

Вилка публикуется по **фактической** ступени; «если бы by» — отдельной строкой как опцион, не как цена.

| Итог атрибуции | Ключ поиска |
|---|---|
| «Признаки соответствуют…» (класс attributed to) | продажи «attributed to [имя]»; полное имя — отдельно, как верхний опцион |
| **«Не опровергнуто» (V1 нет)** | **«объекты с такой атрибуцией в этом эшелоне»: тот же заголовочный класс в сопоставимых домах — компараты болеют тем же, чем лот** |
| Мастерская / studio of | «studio of / workshop of [имя]» |
| Круг / ученик | «circle of [имя]»; школа + период |
| Копия периода | «after [имя]», period copy |
| Поздняя копия / пастиш | декоративный рынок; поздний «manner of» |
| Современная подделка | нижний сценарий: декоративная стоимость минус юридический риск |
| Чужая рука, подпись добавлена | «[школа, период]» без имени |
| Репродукция / тираж | тиражный рынок |
| **«Seal mark of / marked»** | **объекты с такой маркой без периода: «apocryphal mark», «later seal mark»** |
| Firm-made против retailed by | раздельные ключи: изделия фирмы ≠ изделия поставщика под ритейлом |

## Протокол «меньше трёх компаратов»

Сказать прямо. Далее по порядку, каждое расширение — с пометкой: (1) расширить окно лет; (2) поднять класс на ступень обобщения (не «ковш Фаберже», а «русская перегородчатая эмаль этого размера»); (3) сменить ступень источника; (4) всё равно <3 → широкая вилка, ставка строго по нижней границе, строка «выборка несостоятельна» в вердикт цены.

## Запреты

**Будущие торги и стартовые цены — не компараты (v2.4.8, поправка владельца, лот [[2026-10-25-HOTSPOT-455]]).** Блоки «Similar Upcoming Sales» на LiveAuctioneers, цифра рядом с датой будущих торгов, «Starting Bid», эстимейт — это не продажа. Прогон 25.10 выдал $250 и $1 000 (стартовые цены будущих лотов) за «копии уходят за…»; владелец поправил: искать прошлые продажи в архиве. Каждый компарат в отчёте пользователю — со ссылкой на страницу проданного лота.
Эстимейты как компараты — никогда (эстимейт — мнение дома с двумя деформациями, см. pricing.md). Цифры текущего лота — не вход анализа. «Рыночная активность» лота (счётчик ставок) — не данные о стоимости.

## Ступень 1.5 — живые компараты через Perplexity (v2.4.0)

Между архивом под логином и бесплатными архивами результатов: один запрос `sonar` (быстро) или `sonar-pro` (шире) вида «<тип предмета> <атрибуция> sold hammer price 2024 2025 2026 auction» и его же вариант на языке рынка (JP/CN). Ответ — tier-3 черновик: каждую ссылку открыть, взять только ПРОДАННЫЕ с датой, молотком и домом; аски — отдельно с дисконтом (ступень 4). Для меняющихся величин (курс, комиссии, налоги) — в запрос добавить месяц и год (канон §9). Через `scripts/run_role.py --search` или MCP `perplexity_research`.
