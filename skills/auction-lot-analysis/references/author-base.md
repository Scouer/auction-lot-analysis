# База авторов

Локальная накопительная база всех, чьи имена проходят через лоты: художники, мастера, фирмы, регионы-школы. Требование владельца: **перед анализом каждого лота с заявленным автором — полная картина его жизни** (семья, работа, дружба, хобби, путешествия, здоровье, смерть и судьба наследия), накапливаемая и обновляемая при каждом новом факте. Досье — постоянный актив: первый лот имени платит за базу, все последующие читают её почти бесплатно.

## Схема в vault

```
Projects/antique/authors/
  _index.csv        # id,type,name,aliases,category,lots_seen,dossier_tier,
                    # version,updated,fake_list,mirrored
  <slug>/           # kebab-case: gorbatov-konstantin, gu-jingzhou, faberge-firm
    dossier.md      # единый скелет (ниже)
    refs/           # кропы эталонов: подписи, клейма, печати, зоны почерка
    marks.csv       # мастера/фирмы: период,тип знака,описание,статус эталона
                    # (подтверждён/фальшивый),источник,файл
    manner.md       # живопись, Полное досье — по painting/passport.md
```

Правила vault обязательны: markdown, `[[wikilinks]]` на лоты и смежные досье, kebab-case, записи через Desktop Commander. Старое имя `passports/` в текстах навыка = `authors/`.

## Типы досье (один скелет, разный акцент)

| Тип | Акцент |
|---|---|
| **художник** | манера, подпись по годам, корпус, каталог-резоне |
| **мастер** (керамист, ювелир, оружейник) | **печати/клейма по десятилетиям**, резчики печатей, права учеников на знаки, фабрики и артели, преемственность |
| **фирма-мануфактура** | клейма по филиалам и периодам, workmasters/поставщики, retailed-by практика, надштамповки, пробы, судьба после закрытия |
| **регион-школа** (анонимные вещи, режим сужения) | черепок/материалы, палитры, типовые формы, **практика клеймения с частотой** (доля неклеймёного), мастера-партнёры (оловянщики), копиисты историзма, музейные эталоны |
| **карточка имени** (декоративный трек) | ≤10 строк: копийный рынок имени, типовые репродукции, ценовые диапазоны копий, fake-флаг |

## Скелет dossier.md

```markdown
# [Имя] — досье   тип: [художник|мастер|фирма|регион|карточка]
ярус: [К|Я|П] · v0.x · [дата] · лотов через базу: N

## Резюме            # ≤5 строк: годы, где, чем известен, рыночный флаг, fake-флаг
## Жизнь и семья     # происхождение, брак, дети, судьба семьи
## Карьера           # обучение, мастерские/фирмы, должности, ученики и
                     # подмастерья (с датами и правами на знаки), поставщики
## Круг              # дружбы, коллеги, дилеры, покровители, конкуренты,
                     # коллаборации (кто что делал в совместных вещах)
## География         # адреса по годам, путешествия, натурные места, эмиграция
## Хобби и практики  # каллиграфия, коллекционирование, техника — всё, что
                     # оставляет след в вещах
## Здоровье          # зрение, руки, болезни по годам
## Смерть и наследие # дата/место/обстоятельства; судьба мастерской, штампов,
                     # печатей, досок; дисперсия работ; наследники и их права
## Знаки             # подпись/клеймо/печать по периодам (таблица) → refs/, marks.csv
## Рынок и подделки  # корпус, каталог-резоне/архив, инстанции, паттерны
                     # подделок, базовые частоты (→ base-rates), каналы
## Правовое          # реституционные зоны, типичные CITES-материалы, вывоз
## Открытые вопросы  # [?]
## Журнал обновлений # дата — лот/источник — что добавлено
```

Каждая строка несёт метку **E / V1 / M** (дисциплина painting/passport.md распространена на всю базу). Разделы «Жизнь…Смерть» — **накопительные**: пишется полная картина жизни; в отчёт (§5 формы) цитируются строки, реально использованные в вердикте.

## Ярусы глубины

| Ярус | Состав | Бюджет |
|---|---|---|
| **Карточка (К)** | Резюме + fake-флаг + диапазон копийного рынка | ≤5k токенов; чтение из кэша ~1k |
| **Ядро (Я)** | вся биографическая карта (все разделы скелета) + Знаки по периодам + Рынок и подделки; 10–20 E-источников | 20–40k разово; обновление дельтой 3–5k |
| **Полное (П)** | + эталонный и негативный корпусы, f_alt, manner.md, refs/-кропы | +50–100k |

## Протокол

**Строится / повышается:**
- **Любой именной Разбор** (все ярусы, включая Экспресс): досье отсутствует → строится **Ядро** до Фазы 2. Это прямое требование владельца; Экспресс экономит на ролях, не на досье.
- Полный ярус или 3-й лот имени → Полное.
- Имя из fake-списка → Ядро строится сразу (такое имя всё равно получает минимум Стандарт).

**Только читается (строить запрещено):**
- Декоративный трек → Карточка (имя не заявлено как автор — «after X» атрибуции не содержит).
- Исход Запрос → чтение готовой Карточки в парковке.
- Исход Отказ → счётчик lots_seen++ и всё.
- Цейтнот → только кэш; досье не строится, ставка по нижнему сценарию.

**Обновляется:** после каждого именного лота — исход в «Журнал обновлений», новые факты дельтой; **пришли новые данные — сначала обновить досье, потом отвечать** (правило лотов распространено на авторов). Раз в 15–20 лотов Калибровщик сверяет fake-список и частоты с base-rates.

**Слепота:** досье не передаётся Визуальному до конца Фазы 0. На втором проходе Визуальный получает только секции «Знаки»/manner — без текста лота и биографии. Заявления продавца в досье не вносятся: T — претензия, не знание.

**Анонимы:** режим сужения ведёт досье типа «регион-школа» — обновляется после каждого лота, где регион вошёл в круг кандидатов. Владельческие монограммы (гравировка «I.G.S. 1784») — не автор: это провенансная зацепка, живёт в досье лота.

## Биографические тесты (выход Фазы 0.5 → Фаза 2)

Из досье выводятся проверки на противоречие; совпадение с биографией — не плюс (LR≈1: фальсификатор читает те же монографии), несовпадение — минус вплоть до исключения:

1. Даты жизни против датировки и подписи (датировка позже смерти — исключение).
2. География и натура против сюжета (писал ли это место; был ли там к этому году; «по гравюрам» — в репертуаре?).
3. Поставщики и материалы против известного списка (штамп поставщика, которым не пользовался).
4. **Права на знаки:** ученики с правом печати, подписи наследников, посмертные штампы — подлинный знак ≠ рука мастера; смена формы имени датирует (пример: 景洲 → 景舟).
5. Здоровье против продуктивности и техники года.
6. **Судьба наследия против канала находки:** дисперсия наследия (война, распродажа мастерской) делает честные находки в конкретной географии априорно возможными — это законный E-сдвиг канала, не «цена».
7. Насыщение: сколько работ периода известно и сколько «всплыло» на рынке; год, куда рынок «сливает» подделки.

## Облако без vault (режим C)

**Чтение:** зеркало горячей части базы в Project docs (`claude/authors-index.md` = _index + Карточки; Ядра — имён с lots_seen ≥ 2 или из fake-списка). Зеркало обновляет M-сессия батчем (не на каждый лот).
**Запись:** новое/обновлённое досье → staging (Notion «Authors inbox» или Project doc `claude/authors-staged.md`), в хвосте `dossier_updated: true`, `sync_debt: true`. Ближайшая M-сессия обязана проверить staging и влить в vault. Нет и зеркала → Ядро строится из веба штатно (20–40k) и целиком уходит в staging — работа не теряется.

## Секция «Репертуар» (обязательна в Ядре и Полном досье)

Нужна, чтобы вопрос «писал ли он такое» решался справкой, а не догадкой (`iconography.md`, тест 3).

| Сюжет / класс | Периоды | Задокументировано работ | Источник |
|---|---|---|---|

Заполняется по внешним корпусам и пополняется после каждого именного лота (Фаза 6).
Читается так: сюжета нет при богатом корпусе смежных — вопрос; сюжет есть, но в другие годы —
вопрос к датировке; есть и в те же годы — довод нейтральный либо слабо положительный.
**Ни один исход сам по себе дисквалификатором не является**, и отсутствие в доступном корпусе
не равно «никогда не писал» — контрольный запрос обязателен.
