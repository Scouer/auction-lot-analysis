# Атрибуция живописи по фотографиям

Модуль навыка `auction-lot-analysis` для лотов «живопись с заявленным именем» и для режима сужения, когда имя нужно найти. Наследует шкалу V1/V2/V0/E/T/M, правила вердикта, роли, фазы и запрещённые формулировки основного файла; ниже — только то, что специфично для живописи. Раздел «Живопись и графика» в `references/categories.md` остаётся чеклистом состояния, атрибуция идёт сюда.

Основной вопрос модуля не «подлинник ли это», а **чья это рука и на каком основании**. Ответ живёт на атрибуционной лестнице (by / attributed to / studio of / circle of / follower of / manner of / after / copy / forgery / reproduction) и в распределении по гипотезам §3, а не в бинарном да/нет.

Распределение задач модуля по ролям основного файла:

| Роль | Задачи модуля |
|---|---|
| Визуальный аналитик | §2 слепой проход; кропы референсов для паспорта; лист сопоставления §5.2 (с паспортом, без текста лота) |
| Историк-верификатор | паспорт §4: корпусы, источники, подпись по годам, таймлайн, рынок; §7, §8 |
| Ревизор | тесты исключения повторно (перечень — Приложение Р ниже, в этом файле); лучший довод за H7 и H8; один искомый дисквалификатор |
| Коллекционер | условный довод и самая дешёвая проверка — по основному протоколу |
| Директор | потолок §1 + итог §9 → ставка по сценарию |

## 0. Три опоры и три правила

| Опора | Что это | Доступ по фото |
|---|---|---|
| Стилистическая (знаточество) | манера, «почерк», качество, композиция | основной канал; ограничен разрешением |
| Материально-техническая | основа, грунт, пигменты, подрамник, кракелюр, лак, подпись в слое | частично: оборот, кромки, макро, косой свет, УФ — если сняты |
| Документальная | провенанс, публикации, выставки, каталог-резоне, этикетки | только этикетки и надписи на обороте + внешний поиск |

1. **Асимметрия.** Опровергнуть дёшево и надёжно: один анахронизм уровня V1 закрывает авторство. Подтвердить дорого и ненадёжно: сколько бы признаков ни совпало, копиист копирует именно совпадающие признаки. Порядок работы — сначала попытка убить гипотезу автора, потом взвешивание положительного.
2. **Дискриминирующая сила.** Признак — свидетельство только в той мере, в какой он *редок у альтернатив*: ученики, круг, копиисты, фальсификаторы, современники той же школы. «Палитра характерна для автора» — почти ничего (LR≈1): палитру копируют первой. Моторная привычка в «неважной» зоне — много: её не копируют, потому что не замечают.
3. **Потолок по свидетельствам.** Набор снимков заранее определяет максимально возможный вывод (§1). Вывод выше потолка не выносится, какими бы убедительными ни казались снимки.

## Схема на один экран

1. Шлюз: инвентаризация снимков → зоны покрыты? → потолок вывода зафиксирован.
2. Целостность: все снимки одного объекта; обратный поиск по каждому.
3. Слепой проход без имени: объект, техника, состояние, подпись как объект, школа/период диапазоном.
4. Открыть заявленное имя → набор гипотез H1–H9, априор из блока «рынок» паспорта.
5. Паспорт манеры: есть в vault → загрузить; нет → построить (минимальная версия — §4.9).
6. Тесты исключения по возрастанию цены. Противоречие V1 → H1 закрыта; дальше выясняем *что это* — для ценового блока.
7. Лист сопоставления по признакам A→C→B→D: три референса из нужной страты + ближайшая альтернативная рука.
8. «Ожидалось, но отсутствует» / «есть, но не ожидалось» / индикаторы копии.
9. Подпись (§6). Хронология и биография (§7). Провенанс (§8).
10. Синтез: сдвиги от априора построчно, потолок, формулировка по лестнице, следующие проверки с ценником.
11. Состязание по основному протоколу; Ревизор обязан написать лучший довод за H7 и H8.
12. Архив: досье лота + обновление паспорта (новые референсы, новые паттерны подделок, исход).

## 1. Входной шлюз (Фаза −1)

Диагностические зоны живописи. Разрешение — пикселей на зону в самом крупном файле, не в превью.

| Зона | Зачем | Минимум |
|---|---|---|
| Лицевая целиком, фронтально, ровный свет | композиция, формат, палитра, общее состояние | ≥ 2000 px по длинной стороне |
| Косой (боковой) свет | рельеф мазка, фактура холста, деформации, кракелюр, следы подрамника | ≥ 2000 px |
| Макро подписи, даты, надписей | §6 | ≥ 800 px на подпись |
| 3–5 макро «зон почерка» (§4.2) | признаки уровня A | ≥ 1000 px на зону, физический масштаб известен |
| Кромки (tacking margins), углы | грунт, плетение, продолжение живописи за кромку, гвозди/скобы, обрезка | ≥ 800 px |
| Оборот: холст, подрамник, этикетки, штампы, надписи | датировочные пороги, провенанс в материале, дублирование | весь оборот ≥ 1500 px + макро каждой этикетки |
| УФ-флуоресценция | возраст лака, записи, подпись под/над лаком | если дом даёт — запрашивать всегда, это бесплатно |
| Проходящий свет, ИК, рентген | обычно недоступны; запрашивать при высокой ставке | — |
| Рама | второстепенно; этикетки на раме — провенанс | — |

**Целостность снимков — до всего.** (а) Все кадры одного объекта: пропорции, положение трещин и дефектов, место подписи совпадают. (б) EXIF и следы редактирования; несовпадение баланса белого между кадрами — цвет между такими кадрами не сравнивается. (в) Обратный поиск по каждому снимку (Google Lens, Yandex, TinEye): снимок музейной работы вместо снимка лота, прошлые продажи под другим именем, известная копия.

**Потолок вывода по набору свидетельств:**

| Что есть | Максимальный вывод |
|---|---|
| Один фронтальный кадр < 1500 px | «на уровне композиции и сюжета явных дисквалификаторов нет»; атрибуция не обсуждается, только запрос |
| Фронт ≥ 2000 px + макро подписи, без оборота и косого света | исключение по композиции, подписи, анахронизмам сюжета возможно; положительно — максимум «манера не противоречит» |
| + косой свет + 3 зоны почерка + кромки | уровень A сравним; «признаки соответствуют, V1-противоречий нет» достижим |
| + оборот + этикетки + УФ | полный протокол; потолок по фото — класс attributed to; до by — технический анализ и/или носитель каталога-резоне |

## 3. Гипотезы и априор

После открытия имени формулируется полный набор гипотез. Пропущенная гипотеза — самая частая ошибка синтеза: чаще всего забывают H8 и H9.

| Код | Гипотеза | Чем отличается на практике |
|---|---|---|
| H1 | Автограф целиком | уровень A совпадает по всем зонам страты; есть пентименти; внимание к зонам распределено, как у автора |
| H2 | Автограф с существенной реставрацией или записью | уровень A совпадает только в незаписанных зонах; карта записей обязательна |
| H3 | Мастерская, с участием или под надзором | структура и материалы авторские, моторика смешанная или чужая; подпись может быть подлинной |
| H4 | Ученик / ближний круг, современник | те же материалы и школа; чужая моторика; мотивы «из репертуара» |
| H5 | Копия периода с известной работы | композиция известна; жёсткость контура, отсутствие поиска, потери в «неважных» зонах |
| H6 | Поздняя копия или пастиш | материалы позже периода; сборка мотивов из нескольких известных работ |
| H7 | Намеренная современная подделка | искусственное старение, поддельные этикетки, «найденная» работа под описание утраченной, качество сосредоточено там, куда смотрит покупатель |
| H8 | Подлинная работа другой руки с чужой или добавленной подписью | живопись цельная и старая; подпись чужеродна слою; уровень A принадлежит другому автору, нередко хорошему |
| H9 | Репродукция / гибрид | §2 п. 1 |

**Априор** — из блока «рынок» паспорта (§4.7): размер корпуса, полнота каталога-резоне, известная доля подделок по имени, наличие мастерской, учеников и копиистской традиции, ценовой стимул, канал продажи. Канал сдвигает априор, но не является уликой (правило основного файла). Вопрос «почему вещь здесь» задаётся в диффбёрне.

Масштаб проблемы: шутка «Коро написал три тысячи работ, из них десять тысяч находятся в Америке» для ряда имён — не преувеличение; по Айвазовскому эксперты, по распространённым оценкам, отклоняют большинство приносимых на экспертизу работ. Для таких авторов априор H1 у неопубликованной работы из регионального дома — единицы процентов, и никакой набор совпадений уровня B его не поднимет.

**Режим сужения (имя не заявлено).** Итог §2 даёт школу и период → 2–3 кандидатных руки из этого круга → минимальные паспорта (§4.9) на каждую → §5 параллельно. Имя, к которому сошёлся поиск, — тоже гипотеза для опровержения, а не находка.

## 7. Хронология и биография — проверка на противоречие

Из даты (надписанной или стилистической), места, сюжета, формата и материалов кандидата выводится **имплицитная дата и обстоятельство создания**; они тестируются против таймлайна §4.6:

- автор жив, активен, не ослеп, не в дороге без мастерской в этот год;
- натура: изображённое место посещалось до этого года или в него — либо писалось по репродукции, и тогда «по гравюрам» должно быть в репертуаре;
- сюжет в репертуаре периода; модель идентифицируема; формат и основа в употреблении;
- насыщение: сколько работ этого года известно и сколько «нашлось» на рынке за последние годы; год, куда рынок «сливает» подделки, для многих имён известен;
- утраченные работы — только при независимом узле (§4.6).

Совпадение с биографией — не плюс (LR≈1: фальсификатор читает те же монографии). Несовпадение — минус вплоть до исключения.

## 8. Провенанс и документы

Общие правила и юридика — `references/provenance-legal.md`. Специфика живописи:

- Цепочка по узлам; каждый узел внешне проверяем (каталог выставки, аукционный архив, архив галереи, письма, инвентари) или помечен «непроверяем». «Частное собрание, Европа» — не узел.
- Этикетки и штампы: типографика, бумага, клей, номера — против образцов учреждения; запрос в учреждение (архивы галерей и выставок отвечают). Поддельные этикетки и вымышленные узлы — стандартный инструмент: этикетки Флехтгейма у Бельтракки, «мистер X» в деле Кнёдлер/Розалес.
- Прошлые продажи: тот же объект под меньшим именем, снятие с торгов, bought-in — архивы Invaluable, Artnet, Artprice, RKD, Getty Provenance Index, каталоги Sotheby's и Christie's.
- Форма истории («недавно обнаружена», «куплена у художника семьёй», «хранилась на чердаке», «нигде не публиковалась») — не улика; набор без единого проверяемого узла — красный флаг листинга.
- Правило основного файла: отсутствие провенанса — не довод против подлинности. Сфабрикованный узел — сильный довод против и одновременно юридический флаг.

## 9. Синтез и отчёт

### 9.1 Правила

1. Жёсткий дисквалификатор V1 (§5.1), не объяснимый реставрацией зоны, закрывает H1 независимо от суммы положительных признаков. Далее — выбор между H5–H9 по тем же листам, для ценового блока.
2. Без дисквалификатора: сдвиги от априора публикуются построчно (признак → LR-полоса → направление), коррелированные объединены, признаки без негативного корпуса — не выше «слабого». Итог — качественная полоса, не число с запятой.
3. Потолок §1 применяется после сдвигов, не вместо них: сдвиги могут говорить «сильно за», потолок говорит «класс attributed to, не выше».
4. Формулировки по лестнице:
   - противоречие V1 → «не автор; наиболее вероятно H_x; каталожный эквивалент: after / manner of / bears signature / later copy / reproduction»;
   - покрытие зон ниже порога → «недостаточно данных» + запрос;
   - без противоречий, ≥ 3 совпадений уровня A по разным зонам, нет пробелов §5.3 → «признаки соответствуют, противоречий V1 не найдено; класс attributed to; для перехода к by требуются: …»;
   - совпадения B–C при расхождениях A → «круг / мастерская / последователь; авторство не поддержано»;
   - живопись цельная, подпись чужеродна → «H8: другая рука, подпись позднее; ценить как работу [школа, период] без имени».
5. «Подлинник» по фото не выносится. Никогда.

### 9.2 Следующие проверки — с ценником

Ранжирование по (вероятность изменить решение) / (стоимость), как в Фазе 4. Порог применения — «условие сожаления» из Фазы 5.

| Проверка | Что решает | Цена |
|---|---|---|
| Макро зон почерка, косой свет, кромки, оборот, УФ у дома | уровень A, подпись в слое, записи, пороги оборота | бесплатно до закрытия |
| Обратный поиск, архивы продаж, каталоги выставок | копия, прошлые атрибуции, узлы провенанса | бесплатно |
| Литература, каталог-резоне, запрос носителю | есть ли в корпусе; позиция инстанции | дёшево–средне, недели |
| УФ и ИК-рефлектография | подрисунок (привычки уровня A), записи, скрытые изменения | средне |
| Рентген | пентименти (процесс против копирования), плетение — сравнение с работами с того же рулона, гвозди, дублирование | средне |
| XRF, микропробы, сечения | пигменты, грунт, связующее — анахронизмы по Приложению В | дорого; после покупки или по согласию дома |
| Дендрохронология доски, анализ волокон холста | terminus post quem основы | дорого |

### 9.3 Блок в отчёте

В основной структуре отчёта модуль заполняет «Вердикт: подлинность», «Визуальные наблюдения», «Спор», «Что осталось неизвестным» и добавляет подраздел:

```
АТРИБУЦИЯ
  Потолок по свидетельствам:  [строка таблицы §1]
  Паспорт художника:          версия, дата, N по страте; негативный корпус: да / частично / нет; минимальный: да/нет
  Априор H1:                  полоса + основание (E)
  Тесты исключения:           1–7, результат каждого, V-метки
  Лист сопоставления:         таблица §5.2 или путь к файлу
  Отсутствует / лишнее:       §5.3
  Подпись:                    выход §6
  Хронология:                 противоречия / нет
  Провенанс:                  узлы проверенные / непроверяемые / сфабрикованные
  Сдвиги:                     признак → LR-полоса → направление
  Итог по лестнице:           формулировка §9.1 п. 4
  Что изменит вывод:          конкретные наблюдения в обе стороны
  Следующие проверки:         §9.2 с ценами и сроками
```

## 10. Протоколы против смещения (исполнение моделью)

- **Слепота.** Имя не входит в контекст Визуального аналитика до конца Фазы 0; имена файлов референсов обезличены; «узнавание» — M, отдельной строкой.
- **Разделение ролей.** Паспорт строит Историк; сопоставление делает Визуальный аналитик с паспортом, но без текста лота; Ревизор пишет сильнейший довод за H7 и H8 и называет один V1-дисквалификатор, который искал и не нашёл.
- **Конкретность.** Утверждение без кропа и без референса не существует. «Похоже на манеру» — не наблюдение.
- **Различия первыми** (§5.2).
- **Ближайшая альтернатива всегда в кадре.** Вопрос не «похоже ли на X», а «отличимо ли от Y».
- **Запрещённые формулировки**, в дополнение к основному файлу: «характерная для автора палитра / сюжет» как довод за; «узнаваемая манера»; «мастерски написано»; «подпись соответствует» без датированных эталонов; «кракелюр естественный» без косого света; «похоже на [пигмент]»; «работа закрывает пробел в биографии» как довод за; «уверенность 87 %» без построчных сдвигов.
- **Калибровка.** В досье пишется исход: мнение носителя каталога, результат технического анализа, поведение на торгах (bought-in, снятие), последующие продажи. Раз в 15–20 лотов: какие признаки систематически переоценивались, какие страты паспортов пусты, где модель «узнавала» и ошибалась.

## 11. Вычислительный модуль (если строить в коде)

Не заменяет протокол — даёт ещё одну строку в листе сопоставления со своим LR и своей надёжностью.

- **Данные.** Эталонный корпус со стратами и метаданными фото (источник, дата, разрешение, физический масштаб); негативный корпус той же структуры; дедупликация; для каждой работы — все доступные снимки, не один.
- **Предобработка.** Нормализация цвета по карте или gray-world — а лучше отказ от цвета вовсе; приведение к физическому масштабу (px/см из размеров); тайлы режутся из зон почерка, не случайно.
- **Признаки.** Ручные: ориентационные гистограммы по структурному тензору, энергия Габора и вейвлетов по масштабам, GLCM, распределения длины и ширины штриха после сегментации мазка; статистика сети кракелюра на макро. Обученные: эмбеддинги CNN/ViT, дообученные на тайлах «автор против негативного корпуса» — не «автор против всех», иначе классификатор учится отличать жанр. Подпись — методами верификации почерка, отдельно.
- **Модель и валидация.** Тайл → работа (агрегация); калибровка вероятностей; валидация *leave-one-work-out* и обязательно *leave-one-photo-source-out* — падение качества при смене источника фото означает, что модель выучила фотографа; тест на документированных подделках и копиях; AUC и калибровочная кривая по стратам.
- **Ловушки.** Утечка домена фото; загрязнение «эталонного» корпуса неверными атрибуциями (паспорт версионируется именно поэтому); переобучение на знаменитые работы; N < 30 работ в страте — модель не строится, только ручной протокол; выход модели — «похожесть на обучающий корпус», не авторство. Существующие подходы — коммерческие CNN-сервисы и академические работы по анализу отдельного штриха — воспроизводимы на сканах высокого разрешения и спорны на аукционных JPEG; в протоколе их выход — строка с меткой E и указанием разрешения входа.

# Дополнения к мастеру (v1.1, добавлены при интеграции; всё ниже — не авторский текст)

## Д1. Рамка применимости

Модуль — **западная станковая живопись** (масло, темпера; графика частично). Китайская и японская живопись (тушь, свиток, веер, печати, колофоны) сюда **не идёт**: зоны Морелли для масла не переносятся на тушь, копирование там — каноническая практика с собственным рынком, набор гипотез другой, а провенанс живёт печатями прямо на предмете. До появления модуля chinese-painting такие лоты идут по общей воронке; печати сопоставляются инфраструктурой цзыша (`seal_search.py`, флаги фальшивых эталонов); потолок по атрибуции руки — «недостаточно данных».

## Д2. Ярусы исполнения — экономический маршрутизатор

**v2: ярусы стали общими для всех категорий и живут в SKILL.md; таблица ниже — живописная проекция той же логики.** Расхождение трактуется в пользу SKILL.md. Дополнение v2: Ядро досье автора обязательно на любом именном Разборе, включая Экспресс (author-base.md); имя из fake-списка base-rates.md → минимум Стандарт.

Полный прогон на каждый лот невозможен по объёму потока. Ярус выбирается в Фазе −1 и фиксируется в отчёте; молча повышать или понижать ярус запрещено. **Цена лота, эстимейт и ожидаемая ставка в выбор яруса не входят** — глубина разбора определяется данными и повторяемостью имени, не деньгами.

| Ярус | Что выполняется | Условие включения | Потолок вывода |
|---|---|---|---|
| **Экспресс** | тесты исключения без паспорта: обратный поиск, проверка на печать/репродукцию, пороги материалов по обороту и кромкам, композиция против известных работ; подпись только как объект (§6 п. 1–4) | ярус по умолчанию для нового имени | «явных дисквалификаторов нет» / «H_x, наиболее вероятно» |

Паспорта окупаются на повторных именах — это довод сохранять их как постоянные активы (Д5), а не как приложения к досье.

## Д3. Потолок по априору

Итоговый потолок вывода = **минимум** из потолка по свидетельствам (§1) и потолка по априору:

- имя с документированной массовой подделкой (каталоги подделок; доля отклонений профильной инстанцией выше половины; известные «фабрики») → по фотографиям максимум **«манера не противоречит»**, независимо от числа совпадений уровня A;
- переход выше — только через внешний узел: позиция носителя каталога-резоне, публикация, независимо проверяемый провенанс, технический анализ.

## Д4. Ожидание по вердиктам — это конструкция, не сбой

Пока негативные корпусы пусты, ни один признак не поднимается выше «слабого», и вердикты будут системно застревать на «манера не противоречит». Так и задумано. Запрещено «смелеть» без заполненных строк f_alt. Ставка в этом состоянии — по нижнему сценарию, по правилу основного файла.

## Д5. Паспорта в vault

## Приложение Р. Срез Ревизора: тесты исключения (повтор §5.1 comparison.md)

Ревизор прогоняет тесты повторно, по возрастанию цены, не заглядывая в срез Визуального:

1. **Обратный поиск**: известная работа → кандидат — копия, пока не доказано, что это та самая (размеры, провенанс, дефекты); прошлые продажи под другой атрибуцией → диффбёрн и §8.
2. **Печать/репродукция** (§2 п. 1).
3. **Пороги материалов** по обороту и кромкам против датировки, вытекающей из имени.
4. **Подпись и дата** против хронологии подписи (§4.4); дата против биографии (§4.6): жив, работал, был там, писал это.
5. **Негатив-лист** (§4.4): основа, формат, мотив, техника.
6. **Стилистическая датировка против надписанной**: расхождение больше допуска страты — противоречие.
7. **Композиция против корпуса**: полное/частичное/зеркальное совпадение, сборка из нескольких.

Противоречие V1 (V1e — с обязательной пере-проверкой в M до исполнения), не объяснимое реставрацией этой зоны, закрывает H1; дальше определяется, что это (H5–H9). Противоречие V2 не закрывает, а поднимает запрос снимка зоны в шапку. Обязанность Ревизора: лучший довод за H7 и H8 + один конкретный дисквалификатор, который искал и не нашёл.
