# Диагностические зоны и пороги по категориям

Знаменатель покрытия для шлюза (Ш2) и карта прицельного захода Фазы 0. Зоны класса **[Ц]** — несущие ценность: без их снимков исход «Разбор» невозможен. Порог px — по длинной стороне кропа зоны в самом крупном файле; серая зона 300–800 px = «читаемо на V2». Для иероглифики и клейм с мелкими знаками порог считается **на знак**: ≥100 px на знак для чтения, иначе V0 по содержанию.

N_min — минимальное число уникальных снимков для исхода «Разбор». Это пол по категории, не универсальная пятёрка.

Категории, которых нет в таблицах, размечаются по ближайшей и помечаются «чеклист временный» — и добавляются сюда после первого лота (Фаза 6).

## Живопись (западная станковая) — N_min 6
Перенос §1 модуля painting (там же полная таблица):
1. [Ц] Лицевая целиком, фронтально, ровный свет — ≥2000 px
2. Косой свет — ≥2000 px
3. [Ц] Макро подписи/даты/надписей — ≥800 px на подпись
4. 3–5 макро зон почерка — ≥1000 px, масштаб известен
5. Кромки, углы — ≥800 px
6. [Ц] Оборот целиком — ≥1500 px + макро каждой этикетки
7. УФ — запрашивать всегда (бесплатно)
Потолки вывода по набору — таблица §1 модуля painting.

## Китайская/японская живопись (свиток, альбом, веер) — N_min 6
1. [Ц] Лист целиком — ≥2000 px
2. [Ц] Подпись + все печати — ≥100 px на знак
3. Макро мазка/туши 2–3 зоны — ≥1000 px
4. Монтировка, кромки, следы скруток — ≥800 px
5. Колофоны и печати коллекционеров — ≥100 px на знак
6. Оборот/задник — ≥800 px

## Фарфор, керамика, стекло — N_min 5
1. [Ц] Общий вид (фронт + профиль) — ≥1200 px
2. [Ц] Донце целиком (ножка, обточка, следы опор) — ≥1000 px
3. [Ц] Клеймо/марка макро — ≥800 px (или ≥100 px на знак)
4. Венчик/носик/ручки/выступы (зоны боя) — ≥800 px
5. Внутренняя поверхность — ≥800 px
6. Декор макро (кисть/печать/деколь) — ≥800 px
7. Скол/повреждение, если заявлено — ≥600 px

## Цзыша (Yixing) — N_min 6
1. [Ц] Профиль и фронт — ≥1200 px
2. [Ц] Печать на донце — ≥800 px, ≥100 px на знак
3. [Ц] Печать под крышкой / на ручке — ≥500 px, ≥100 px на знак
4. Посадка крышки (вид сверху без крышки + с крышкой) — ≥800 px
5. Внутренняя поверхность и стыки (следы соединения) — ≥800 px
6. Фактура глины макро (зернистость) — ≥800 px
7. Носик и слив изнутри — ≥600 px

## Серебро и металл — N_min 5
1. [Ц] Общий вид (верх + профиль) — ≥1200 px
2. [Ц] Вся группа клейм макро — ≥800 px на группу И ≥100 px на знак; прямой и косой свет
3. Донце/основание — ≥800 px
4. Стыки, пайки, крепления ручек — ≥800 px
5. Внутренняя поверхность (лужение/золочение) — ≥600 px
6. Гравировки/гербы/надписи — ≥600 px
7. Вес заявлен числом (не фото, но обязательное поле; вес против размера — быстрый индикатор)

## Мебель — N_min 8
1. [Ц] Общий вид со всех сторон (фронт/бок/зад) — ≥1500 px
2. [Ц] Соединения (ласточкин хвост, шипы) макро — ≥800 px
3. Задняя стенка / дно / внутренности ящиков — ≥1000 px
4. Фурнитура + следы старых отверстий — ≥600 px
5. Ножки/полозья снизу — ≥800 px
6. Столешница/шпон макро — ≥800 px
7. Следы инструмента на неотделанных поверхностях — ≥800 px
8. Замки/петли — ≥600 px

## Часы — N_min 6
1. [Ц] Циферблат целиком — ≥1000 px
2. [Ц] Механизм (при открытой крышке/задней стенке) — ≥1000 px
3. [Ц] Номера корпуса и механизма — ≥100 px на знак
4. Корпус со всех сторон, грани — ≥800 px
5. Клейма корпуса — ≥800 px
6. Комплект (ключ, коробка, бумаги) — ≥600 px

## Иконы — N_min 6
1. [Ц] Лицевая целиком — ≥1500 px
2. [Ц] Оборот доски целиком (шпонки, торцы) — ≥1000 px
3. Лик(и) макро — ≥800 px
4. Поля и ковчег, стык — ≥800 px
5. Утраты/записи/раскрытие — ≥800 px
6. Оклад и его клейма (если есть) — ≥800 px, ≥100 px на знак

## Ковры и текстиль — N_min 5
1. [Ц] Целиком с лицевой — ≥1500 px
2. [Ц] Оборот с узлами макро — ≥800 px (плотность считается)
3. Края и концы (бахрома, кромка) — ≥800 px
4. Ворс макро в 2 зонах (износ, цвета) — ≥800 px
5. Дефекты/перештопка — ≥600 px

## Книги и рукописи — N_min 5
1. [Ц] Титульный лист — ≥1000 px
2. [Ц] Колофон/выходные данные — ≥800 px
3. Переплёт (крышки, корешок) — ≥800 px
4. Развороты с иллюстрациями/картами — ≥800 px
5. Дефекты, экслибрисы, штампы — ≥600 px

## Ювелирные изделия — N_min 5
1. [Ц] Общий вид (несколько ракурсов) — ≥1000 px
2. [Ц] Клейма/подпись/номер — ≥100 px на знак
3. Камни макро (каждый значимый) — ≥800 px
4. Оправа с оборота (крепление, следы переделки) — ≥800 px
5. Застёжка/шарниры — ≥600 px

## Монеты, медали, малые предметы — N_min 2
1. [Ц] Аверс — ≥1200 px
2. [Ц] Реверс — ≥1200 px
3. Гурт (для монет с гуртовой надписью) — [Ц] при заявленной редкости

## Оловянные монтировки (модификатор к керамике/стеклу)
+1 зона [Ц]: проба оловянщика изнутри крышки — ≥600 px; посадка монтировки (родная/поздняя) — вид стыка.
